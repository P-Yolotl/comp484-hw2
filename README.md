structural HTML elements:
'nav' is used inside the main header to contain the navigation links to the other pages of the website. It also uses `role="navigation"` to identify it as the navigation area.
'article' contains the main article and information of the page.
'section' is used to divide the article into separate topics. Which are "Sectioning elements," "Document outlines," and "WAI-ARIA Roles."
'aside' is used inside the "Document outlines" section for the W3C Warning. The information is related to the main content but is additional information. It uses `role="complementary"`.

ARIA roles used in the page:
role="main" on the main content
role="banner" on the main header
role="navigation" on the navitation menu
role="complementary" on the aside
role="contentinfo" on the footer

C. Semantic Tags
'header' contains the page title, subtitle, and navigation. A second 'header' is used to introduce the article.
'main' contains the primary page content.
'footer' contains the CSUN link and address.
'nav' contains the site navigation links.
'article' contains the main article content.
'section' separates the article into different topics.
'aside' contains supporting information related to the main content.
